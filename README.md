# Ansible Collection - brocktech.gitea

Collection of utilites to limit how much I am relying on things like ansible's changed_when.

## Modules

### brocktech.gitea.user

This module will create/update/delete users in the gitea api.

### brocktech.gitea.organization

This module will create/update/delete organizations in the gitea api.

### brocktech.gitea.variable

This module will create/update/delete variables within organizations in the gitea api.

### brocktech.gitea.secret

This module will create/update/delete secrets within organizations in the gitea api.
