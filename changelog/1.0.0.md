## Modules

### brocktech.gitea.user

- Create/Update/Delete users within the Gitea application using the API.
- Will do updates in place for all non-secret properties.
- Updates can be forced for secret properties like passwords.

### brocktech.gitea.organization

- Create/Update/Delete organizations within the Gitea application using the API.
- Will do updates in place for all properties.
- Adds members to the "Owners" team currently, no options to create any other teams.

### brocktech.gitea.variable

- Define a variable that can be used within Gitea Actions.
- Currently variables can only be set at the Organization level.
- Variables are only for explicitly non-secret data so this will only be updated when data changes.

### brocktech.gitea.secret

- Define a secret that can be used within Gitea Actions.
- Currently secrets can only be set at the Organization level.
- Secrets can never be read from the API so updates are only performed when `force_update: true` is set.
